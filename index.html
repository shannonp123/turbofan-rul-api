Turbofan Engine RUL Prediction

This page calls a live REST API (FastAPI). It sends the last 30 cycles of an engine's sensor readings to the LSTM model and shows the remaining useful life. Manuf-Project 2, CSE4007L.

Endpoints: GET /health · GET /example/{engine} · POST /predict · interactive docs at /docs

1. Predict for a test engine

Choose an engine and press Predict. The page loads its last 30 cycles and sends them to the model.

2. Or send your own readings (JSON)

API pages: /docs (interactive documentation) and /health. Data is simulated NASA C-MAPSS FD001 (one operating condition, one fault mode); the model is for learning and has not been validated on real aircraft. Send 30 cycles for reliable results.
